## [2026-05-17] - السكرتير الشخصي المتكامل 100%

### Added
- **نظام متابعة الوثائق** (`models/Document.js`)
  - تخزين وتتبع كل الوثائق (إقامة، رخصة، جواز، استمارة، تأمين، عقد إيجار...)
  - حساب تلقائي للأيام المتبقية والأيام المتأخرة
  - تنبيهات ذكية قبل انتهاء الصلاحية
- **قوانين الحكومة السعودية** (`services/governmentService.js`)
  - خطوات التجديد لكل وثيقة (مع وصلات رسمية)
  - جدول المخالفات المرورية والغرامات
  - جميع المنصات الرسمية (أبشر، إيجار، تأميني، قوى، بلديتي...)
  - الأوراق المطلوبة لكل إجراء
  - نصائح وتوصيات ذكية
  - حساب الغرامات التقديرية
  - اقتراح أفضل وقت للتجديد
- **مُجدول ذكي** (`services/schedulerService.js`)
  - اقتراح الوقت المناسب لكل مهمة (مع الساعة والدقائق)
  - إعادة ترتيب الأولويات تلقائياً
  - خطة يومية مع تنبيهات الوثائق
  - نظام متابعة المهام المتأخرة وإزعاج المستخدم
- **التحية الصباحية اليومية**: لما تقول "صباح الخير" يعرض لك:
  - عدد المهام والمواعيد
  - المهام المتأخرة
  - الوثائق على وشك الانتهاء
  - الأولويات اليومية مع اقتراح الوقت
- **الرد على استفسارات الوثائق في الشات**:
  - "/chat" يفهم أي استفسار عن الإقامة، الرخصة، الاستمارة، الجواز
  - يعرض الخطوات والرسوم والروابط مباشرة
- **API للوثائق** (`/api/documents`): CRUD كامل + فحص الصلاحية + حالة كل وثيقة
- **API للجدول** (`/api/schedule`): خطة يومية + اقتراح وقت + إعادة جدولة + متابعة
- **API للتحية الصباحية** (`/api/schedule/checkin`)
- **API للمتابعة والإزعاج** (`/api/schedule/nag`)

### Added
- **فهم الجمل المركبة**: النظام الآن يفرّق بين عدة برامج/مواعيد في رسالة واحدة
  - يفصل بـ "و"، "ايضا"، "كمان" بشكل صحيح (دون كسر الكلمات العربية)
  - يستخرج كل مهمة ويحلّلها بشكل مستقل
- **الإنشاء التلقائي الذكي**: عندما يرسل المستخدم قائمة برامج:
  - يقسمها تلقائياً
  - يصنف كل برنامج حسب نوعه (طبي، سفر، اجتماعي...)
  - يحدد الأولوية تلقائياً (urgent للطبي، high للسفر...)
  - يحدد تاريخ تقديري إذا ما حدد المستخدم تاريخ
  - ينشئ جميع المهام دفعة واحدة
- **واجهة Chat جديدة**: تركز على الاستجابة السريعة للمهام بدل الدردشة المطولة
  - `POST /api/chat`: يفهم المهام وينشئها مباشرة، يرد على التحيات بشكل طبيعي

- `extractTitle`: يزيل "غداً" بشكل صحيح مع التنوين
- إضافة كلمات مفتاحية: "سافر"، "اسافر"، "ضيوف"، "عزومة" لاكتشاف أفضل
- `smartPriority`: يشمل iqama, visa, passport كأولوية urgent

### Changed

  - يفحص الرسالة لتقسيمها إلى مهام متعددة
  - ينشئ المهام تلقائياً لكل عنصر واضح
  - يستخدم `guessDate()` لتقدير التاريخ حسب الفئة
  - يستخدم `smartPriority()` لتحديد الأولوية حسب الفئة
  - يرجع رد منظم بالأيقونات والأولويات
- تحديث `KEYWORDS` في aiService.js: توسيع تغطية الفئات

## [2026-05-17] - تحديث الذكاء 2.0 - سكرتير طبيعي بذاكرة ومحادثة

### Added (New Files)
- **ذاكرة المحادثة** (`services/conversationMemory.js`):
  - تتبع سير المحادثة لكل مستخدم (آخر 50 رسالة)
  - سياق المحادثة: الموضوع الحالي، الموضوع السابق، المهام المعلقة
  - كشف المتابعة: يعرف إذا المستخدم يكمل على نفس الموضوع
  - تفضيلات المستخدم: لغة، وقت التذكير، إعدادات الإزعاج
  - إدارة المواضيع المنطوق عنها (الوثائق المذكورة سابقاً)
  - كشف التأكيد/النفي ("تمام" = yes، "لا" = no)
- **محرك NLP عربي** (`services/arabicNLP.js`):
  - فهم 15+ نية مختلفة (تحية، سؤال، طلب مهمة، استفسار وثيقة...)
  - كلمات استفهام عميقة: وش، شو، ماذا، كيف، ليه، ليش، متى، وين، من، كم، هل
  - استخراج الأفعال العربية: ذكر، ضيف، حضر، شوف، سوي، طلب، جدد، سدد...
  - التعرف على ضمائر الإشارة (ها، ه، هذا، هذه، ذا، ذي) لفهم المتابعة
  - كشف الموضوع الجديد: يعرف متى المستخدم بدأ موضوع جديد
  - ١٠ قواعد زمنية: بكره، بعد غد، الأسبوع الجاي، الشهر القادم، أيام الأسبوع...

### Added (Enhanced Features)
- **محادثة متعددة الجولات**: السكرتير الآن يفتكر وش كنت تقوله قبل ويرد في السياق
  - مثال: "وش خطوات الإقامة؟" ← يرد بالخطوات → "وكم رسومها؟" ← يفهم انك تقصد الإقامة
  - مثال: "عندي موعد" ← "وش التاريخ؟" ← "بكره" ← يفهم انه نفس المهمة
- **تأكيد المهام**: يسأل المستخدم "أمشي في الإضافة؟" قبل إنشاء المهمة
- **دول جديدة** في `governmentService.js`:
  - **🇦🇪 الإمارات**: تأشيرة، بطاقة عمل، مخالفات، منصات (ICP، MOHRE، TAMM)
  - **🇪🇬 مصر**: جواز سفر، رخصة قيادة، تراخيص مركبات، مخالفات، منصات
- **جدولة أذكى**: تراعي تفضيلات وقت العمل، أيام الجمعة، الصباح/المساء، ضغط المهام
- **تكامل NLP + memory**: aiService.js يعيد استخدام الذاكرة لتجنب الأسئلة المتكررة

### Changed
- **aiService.js**: إعادة بناء كاملة
  - يستخدم `arabicNLP` للتصنيف الذكي بدل `fallbackChat` الطويل
  - يستخدم `conversationMemory` لسياق المحادثة
  - ردود ذكية حسب النية والموضوع الحالي
  - معالجة المتابعات الآلية (follow-up questions)
  - طلب تأكيد قبل إنشاء المهام
- **chat.js**: استخدام NLP + Memory لتحسين تدفق المحادثة
- **schedulerService.js**: اقتراح وقت يأخذ بعين الاعتبار الإجازات ويوم الجمعة
- **governmentService.js**: إضافة مصر والإمارات كدول جديدة بدعم كامل

### Fixed
- تجاهل "و" العطف في `splitItems` عند وجود مسافة قبلها
- تحسين استخراج أسماء الوثائق من النصوص العربية الفصحى والعامية
